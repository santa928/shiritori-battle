# 同義の別表記の表示

辞書検索・対戦の成功表示・結果履歴は `web/candidate-groups.mjs` の共通処理でカードを作ります。語義や採用判定、元の辞書区画、対戦ルールは変更しません。

`web/meaning-equivalences.mjs` は固定版の原文を照合した対応表です。初回は365組・734件の原語義を対象にします。学術的表記と通常表記の対応、および同一定義と共通表記の確認済みの組です。参照先を確認できない「あかあさだ」は保留しています。例：ワニ/鰐、カエル/蛙、ミカン/蜜柑。読みだけの一致、似た文章、同じ代表表記だけではまとめません。橋/箸/端、犬の動物/スパイのような異なる意味は別カードです。

全メンバーの出典ID・項目ID・語義ID・出典URL・読み・表記・品詞・日本語定義が固定データと一致し、全て採用可能なときだけ一つのカードにします。一部が欠ける、対象外になる、出典更新で一致しなくなる場合は別々に表示します。対象外の語義は辞書画面に独立して残し、対戦には採用しません。

各カードは全メンバーの原文定義・別表記・元記事リンク・項目/語義IDを保持します。確認済みの代表語義を1件表示し、「出典ごとの説明」を開くと各原文・分類・出典を確認できます。代表語義は対応表で明示し、「学術的表記」という参照文より通常表記の説明を優先します。「別名」「略」等の原文は推測で書き換えません。成功表示は最大2件のカードと先頭の定義だけを表示し、結果履歴には全定義と出典を表示します。「件」は表示カード数であり、原資料の語義数や得点ではありません。

対応表を増やす場合は、両方の定義を実際に確認して語義単位で対応づけてください。例えば「マイマイ」の参照先候補「舞舞」は踊りの意味であり、自動対応させられません。未確認の候補を一括採用しないでください。辞書版を更新した際も対応表の自動移行はせず、再照合します。

「はし/箸」の食器の語義は、原文先頭の自分自身の読み注記「（はし）」だけが異なることを確認して固定対応に追加しました。吹きガラスの道具の語義は別のままです。この注記の除去は候補調査時だけで、実行時の自動統合や原文改変には使いません。

追加調査では、完全一致する自分の読み注記「（読み）」のみを取り除いた定義が一致し、読み以外の表記も共有する104組を原資料と照合しました。重複関係をまとめた101グループ・205原語義を固定表へ追加しています。使用年代などの分類が異なる場合も、原語義ごとの分類を説明詳細に保持します。

2026-10-05の同型読み欠落補完では、原資料の語義を再確認した15組を追加し、既存の鮫1組に同じ定義の語義を1件追加しました。合計380組。既存364組・既存365代表語義は不変です。新対応は `similar-reading-equivalences.json` の固定原レコードSHAと語義単位のガードを使い、読み・表記からの実行時推定は行いません。頬の「ほお/ほほ」、脛の「すね/はぎ」は別々の読み限定の対応です。鯨の広義と大型種の区別、キュウリの植物/果実、鍵の道具/錠/手掛かり/暗号データ、秋刀魚と麻雀、提灯と焼き鳥、瓶の別語義を混ぜません。
