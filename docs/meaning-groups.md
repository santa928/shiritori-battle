# 同義の別表記の表示

辞書検索・対戦の成功表示・結果履歴は `web/candidate-groups.mjs` の共通処理でカードを作ります。語義や採用判定、元の辞書区画、対戦ルールは変更しません。

`web/meaning-equivalences.mjs` は固定版の原文を照合した対応表です。初回は264組・529件の原語義を対象にします。学術的表記と通常表記の対応、および同一定義と共通表記の確認済みの組です。参照先を確認できない「あかあさだ」は保留しています。例：ワニ/鰐、カエル/蛙、ミカン/蜜柑。読みだけの一致、似た文章、同じ代表表記だけではまとめません。橋/箸/端、犬の動物/スパイのような異なる意味は別カードです。

全メンバーの出典ID・項目ID・語義ID・出典URL・読み・表記・品詞・日本語定義が固定データと一致し、全て採用可能なときだけ一つのカードにします。一部が欠ける、対象外になる、出典更新で一致しなくなる場合は別々に表示します。対象外の語義は辞書画面に独立して残し、対戦には採用しません。

各カードは全メンバーの原文定義・別表記・元記事リンク・項目/語義IDを保持します。確認済みの代表語義を1件表示し、「出典ごとの説明」を開くと各原文・分類・出典を確認できます。代表語義は対応表で明示し、「学術的表記」という参照文より通常表記の説明を優先します。「別名」「略」等の原文は推測で書き換えません。成功表示は最大2件のカードと先頭の定義だけを表示し、結果履歴には全定義と出典を表示します。「件」は表示カード数であり、原資料の語義数や得点ではありません。

対応表を増やす場合は、両方の定義を実際に確認して語義単位で対応づけてください。例えば「マイマイ」の参照先候補「舞舞」は踊りの意味であり、自動対応させられません。未確認の候補を一括採用しないでください。辞書版を更新した際も対応表の自動移行はせず、再照合します。
